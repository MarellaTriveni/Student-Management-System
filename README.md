# 🎓 Student Management System

A beginner-friendly Student Management System built using Python and Object-Oriented Programming (OOP).

## 📌 Project Description

This project is designed to manage basic student information such as:

* Student Name
* Roll Number
* Department
* Email

The current version demonstrates Python classes, objects, constructors, and methods.

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)
